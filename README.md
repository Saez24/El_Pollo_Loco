# 🕹️ Jump-and-Run Browser Game

A fun and dynamic **jump-and-run browser game** – not just for kids! 👦👧  
You take control as the hero behind the action, implementing the core **game logic** using **object-oriented programming (OOP)** in JavaScript.

## 🚀 Overview

This project is a side-scrolling platformer built with **HTML**, **CSS**, and **JavaScript**, using **object-oriented principles** to organize the game's structure, characters, physics, and interactions.

## 🎮 Features

- 🦸 Control a playable character with keyboard input
- 🌍 Side-scrolling level design
- 🧱 Obstacles, platforms, and gravity-based movement
- 💥 Collision detection and simple physics
- 🔁 Game loop built with JavaScript animation frames
- 🧠 Modular code structure with classes and reusable objects

## 🧪 Technologies

- **HTML5 Canvas** – Rendering the game world
- **CSS3** – Styling layout and UI elements
- **JavaScript (OOP)** – Game logic, classes, event handling

## 🧱 OOP Concepts Used

- Classes & Instances
- Inheritance & Composition
- Encapsulation of behavior and properties
- Modular, maintainable code architecture

## How to Play

```bash

git clone https://github.com/Saez24/El_Pollo_Loco
cd El_Pollo_Loco

```

Run the game:

Open index.html in your browser – no installation required!

Controls:

⬅️➡️ Arrow keys – Move left/right
⬆️ or Space – Jump
